# GUI-Explorer baseline

Run the **GUI-Explorer** agent (ACL'25, *Autonomous Exploration and Mining of
Transition-aware Knowledge*) on our navigation tasks and judge the results
against ground-truth target screens.

We use GUI-Explorer's **shipped knowledge base** and their retrieval/guideline
pipeline as-is — exploration is **not** re-run. This adapter only handles
emulator control, our task format, and trajectory/summary logging; the upstream
agent code is loaded from an external checkout at runtime.

## Memory system (what we download and inject)

- **Where it comes from.** GUI-Explorer's memory is a *transition-aware knowledge
  base* shipped as a single `knowledge_base/knowledge_data.pkl` (~19 MB) in their
  GitHub release. We **download and use it as-is** — their RAG server loads it and
  we do not re-mine. (It can also be regenerated by their autonomous
  exploration + mining pipeline, but we used the shipped artifact for a fixed,
  faithful baseline.)
- **Format (how it's built).** For each exploration step that *changes the screen*
  (before→after screenshots differ by perceptual hash), they crop the **image
  patch of the tapped UI element** and a VLM writes a 1–2 sentence **functional
  caption** ("tapping this opens search"); near-duplicate patches are fused via
  SigLIP embeddings. So one entry = **(element image-patch → short functional
  text)**, grouped per app — a *flat bag of element affordances*, with no screen
  graph and no routes.
- **Retrieval at inference.** Each step, the adapter sends the current screen's
  element crops to the RAG server, which returns the most **image-similar** stored
  captions; a reranker keeps the most useful and they are injected into the prompt
  as "expert tips."  Memory flow: **screenshot → per-element patch → image-similarity
  lookup → text hint.**

## Files

| File | Purpose |
|------|---------|
| `run_benchmark.py` | Run the GUI-Explorer agent over one app's tasks → per-task `summary.json` + `agent_screenshot.png` + `all_summaries.json` |
| `run_all_apps.sh` | Loop `run_benchmark.py` over the app subset, then summarize |
| `strict_judge.py` | GPT-4o strict judge: final agent screenshot vs. ground-truth final frame (score 4–5 = success) |
| `summarize.py` | Aggregate `all_summaries.json` across apps into a CSV/MD table |

## Required environment

Set these in `baselines/.env` (copy from `baselines/.env.example`):

| Variable | Meaning |
|----------|---------|
| `GUI_EXPLORER_ROOT` | Path to an upstream GUI-explorer checkout (under `baselines/external/`) |
| `GUI_EXPLORER_RAG_URL` | Where the upstream retrieval server is reachable (used by the upstream agent config) |
| `TAGNAV_TASKS_ROOT` | Root holding per-app task folders (each task subdir has a `prompts.json`) |
| `TAGNAV_GT_ROOT` | Ground-truth root with per-app `frame_*.png` (defaults to `TAGNAV_TASKS_ROOT`) — judging only |
| `OPENAI_API_KEY` | GPT-4o backbone + strict judge |
| `ANDROID_DEVICE_SERIAL` | adb serial of the running emulator/device |

## Steps (from a fresh clone)

```bash
# 1. Python deps (this repo's env + GUI-Explorer's requirements)
pip install -r ../external/GUI-explorer/requirements.txt pillow uiautomator2 openai

# 2. Clone the upstream model and point GUI_EXPLORER_ROOT at it
cd baselines/external
git clone https://github.com/JiuTian-VL/GUI-explorer.git GUI-explorer
cd -

# 3. Configure
cp baselines/.env.example baselines/.env
#   edit baselines/.env: GUI_EXPLORER_ROOT, TAGNAV_TASKS_ROOT, OPENAI_API_KEY, ANDROID_DEVICE_SERIAL

# 4. Start GUI-Explorer's retrieval server (serves their shipped knowledge base)
#    from the upstream checkout, then point GUI_EXPLORER_RAG_URL at it.
#    See the upstream README for the exact server entrypoint + how the shipped
#    knowledge_base/knowledge_data.pkl is loaded.

# 5. Start an emulator/device with the target app installed (adb devices)

# 6. Run one app
set -a; . baselines/.env; set +a
python baselines/gui_explorer/run_benchmark.py \
    --app clock --device "$ANDROID_DEVICE_SERIAL" \
    --max-steps 15 --out-dir results/gui_explorer/clock

# …or the whole subset
bash baselines/gui_explorer/run_all_apps.sh        # DRY_RUN=1 to preview commands

# 7. Judge + summarize
python baselines/gui_explorer/strict_judge.py --root results/gui_explorer
python baselines/gui_explorer/summarize.py --roots results/gui_explorer
```

## Hard dependencies a developer must supply

- **A running GUI-Explorer retrieval server + the shipped knowledge base.** The
  agent retrieves per-element knowledge through this server every step; without
  it the agent cannot run. Start it from `GUI_EXPLORER_ROOT` and point
  `GUI_EXPLORER_RAG_URL` at it. (LinkedIn has no entry in the released KB, so it
  is excluded by default in `run_all_apps.sh`.)
- **An Android emulator/device** with each target app pre-installed, reachable
  via `adb`.
- **Task data** under `TAGNAV_TASKS_ROOT` (per-app dirs with `prompts.json`) and,
  for judging, ground-truth `frame_*.png` under `TAGNAV_GT_ROOT`.
- **`OPENAI_API_KEY`** for the GPT-4o backbone and the strict judge.
